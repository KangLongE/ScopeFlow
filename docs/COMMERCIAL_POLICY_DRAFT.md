# ScopeFlow 유료 이용 조건 초안

상태: **미확정·검토용**. 요금·결제·자동 갱신·유료 구독 기능을 구현하거나 활성화하지 않았다. 이 문서는 확정된 유료 계약·이용약관·개인정보 처리방침을 대신하지 않는다.

운영자: 강태현. 문의: scopeflowservice@gmail.com. 사업자등록 관련 정보와 개인정보 담당·보유·삭제 정책은 추가 확정이 필요하다.

## 현재 제공 기능과 AI 처리

고객·프로젝트 관리, 고객 질문·답변, 요구사항 검토, 역할별 견적, Scope 작성·승인 이력, 변경 요청 비교·승인, 회사 소유자의 데이터 내보내기를 제공한다. AI 결과는 담당자 검토 초안이다. 자동 승인이나 AI 산정의 정확성을 보증하지 않는다.

작업별 Credit의 기준 소스는 `Backend/src/lib/ai/usage-policy.ts`이며, 공개 안내는 `/api/v1/service-policy`를 통해 같은 값을 조회한다. 월 한도는 Workspace와 그 안의 사용자 설정을 함께 적용한다. 관리자가 지정하는 한도와 유료 상품 구매량은 구분한다. 월 기간의 시작은 UTC 1일이다.

- 검토 가능한 결과가 성공 저장된 실행은 1회 차감한다. 담당자가 확정하기 전이어도 성공한 초안 저장은 차감 대상이다.
- 제공자 오류·토큰 한도·응답 형식 오류 등 확정 실패는 미차감이며 예약을 해제한다.
- 실행 중에는 예약한다. 결과 불명 상태는 기존 실행 확인이 우선이며 자동 재실행·임의 환급으로 설명하지 않는다.
- 동일 입력의 유효 캐시 재사용은 추가 차감하지 않는다. 명시적인 새 실행은 별도 비용 안내를 거친다.
- Credit 차감과 원화 결제 환불은 별개의 개념이다. 현재 원화 결제는 제공하지 않는다.

## 유료 서비스 개시 전에 확정할 항목

| 항목 | 현재 상태 | 확정할 내용 |
| --- | --- | --- |
| 요금·부가세·주기 | 미정 | 월/연 요금, 부가세 포함 여부, 결제일 |
| 제공량 | 미정 | 좌석·프로젝트·저장 용량·월 Credit·추가 구매 |
| 한도 초과 | 실행 차단 구현 | 초과 과금 여부, 알림, 상향 절차 |
| 이월·소멸 | 상품 정책 미정 | 주기 종료·해지 시 미사용 Credit 처리 |
| 해지 | 구독 기능 없음 | 다음 갱신 중단, 남은 이용 기간, 신청·확인 경로 |
| 환불 | 원화 결제 없음 | 미사용·일부 사용·중복 결제·서비스 미제공별 기준과 계산식 |
| 장애·오류 | AI 실패 미차감 구현 | 청구 오류 정정, 장애 보상과 처리 기한 |
| 데이터 | JSON 내보내기 구현 | 해지 후 접근·보유·삭제 기간, 요청·확인 방식 |

검토 방향: 중복 결제·서비스 미제공에 대한 환급, 해지 시 다음 자동 갱신 중단, 미사용 기간·Credit의 처리 기준을 상품 유형에 맞게 구체화한다. 기간·환급율·공제액을 임의로 확정하지 않는다. 화면에서 쉽게 찾을 수 있는 해지·환불 신청과 접수 확인을 제공한 뒤 유료 판매를 시작한다.

전자상거래·디지털 서비스의 청약철회·환급 기준과 적용 대상은 실제 판매 방식, 공급 개시, 고지·동의 및 고객 유형에 따라 검토해야 한다. 초안이 법정 권리를 제한한다고 표시하지 않는다. [국가법령정보센터 전자상거래법 제17조](https://www.law.go.kr/법령/전자상거래법/제17조)를 기준으로 실제 상품 조건의 적용 여부와 환급 절차를 확정한다.

## 공개 안내와 출시 조건

`/service-policy`는 현재 기능과 Credit 처리, 준비 중인 유료 조건을 명확히 구분해 보여준다. 로그인 페이지와 Workspace 설정에서 접근한다. 고객 문의 이메일은 실제 운영자가 제공한 주소만 사용한다.

유료 판매 전에는 사업자 정보, 실제 요금·제공량·해지·환불 기준, 개인정보 처리방침·보유·삭제·위탁·국외 이전 사항, 운영 백업·복구 상태를 확인한다. 이 문서 작성만으로 결제나 구독을 활성화하지 않는다.
