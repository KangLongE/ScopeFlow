# ScopeFlow 검증 기록

검증일: 2026-09-15. Windows 로컬 실행, Next.js 운영 빌드, PostgreSQL 엔진 PGlite를 사용했습니다. 브라우저 데이터는 가상 고객·가상 프로젝트이며 외부 고객에게 메시지를 발송하거나 계약을 체결하지 않았습니다.

## 검증한 사용자 흐름

담당자의 고객·프로젝트 생성 → 문의·질문·요구사항 입력 → 서버 견적 계산 → Scope 공유 → 고객 승인 → 추가 요청 검토 → 고객 변경 승인 → 새 Scope와 누적 견적 표시.

| 경계 | 결과 | 근거 |
|---|---|---|
| 로그인·UI | 확인 | Better Auth 가입·로그인 후 Workspace, 고객, 프로젝트를 실제 화면에서 생성 |
| UI → API | 확인 | 폼 제출 후 요구사항·질문 답변·시간·견적이 저장되어 다시 표시됨 |
| API → DB | 확인 | PGlite 영구 저장 및 서버 재시작 후 데이터 유지; 자동 테스트는 별도 메모리 DB |
| 고객 Scope 승인 | 확인 | 고객 링크에서 v0.1을 승인해 v1.0으로 전환 |
| 변경 승인 → 새 버전 | 확인 | 리뷰·별점 변경 승인 후 v1.1, 요구사항 3개, 총액 474만 원 표시 |
| 이전 데이터 보존 | 확인 | v1.0을 다시 열면 400만 원·30일·11월 30일·원래 제외 항목 유지 |
| 대시보드 | 확인 | 진행 프로젝트 1, 승인 대기 0, 변경 검토 0, 완료일 12월 2일 표시 |
| 브라우저 콘솔 | 확인 | 최종 대시보드에서 error/warn 로그 없음 |
| 실제 AI 공급자 | 미검증 | 실행 환경에 실제 API 키 없음; 앱은 AI 미연결 상태를 명시 |

브라우저 테스트의 기본 견적은 415만 원입니다. 담당자가 이유와 함께 400만 원으로 조정했고, 추가 시간 Frontend 6h + Backend 6h + QA 2h에 회사 단가를 적용한 74만 원이 합산되어 474만 원이 되었습니다. 일정은 30일 → 32일, 완료일은 2026-11-30 → 2026-12-02입니다.

## 자동 테스트 범위

1. 견적 산술, 음수 입력 차단, 달 경계·윤년·잘못된 날짜 검증.
2. 가입·로그인·세션, 미인증 API 401, 외부 Origin 403, Workspace·고객 격리, MEMBER의 OWNER 작업 제한.
3. AI 초안 → 질문 답변 → 요구사항 → 작업량 검토 → Scope 승인 → 변경 승인 전체 서비스 흐름. DB의 승인 문서 수정·삭제 차단, 중복 승인 시 단일 버전·단일 감사 이벤트, 원본 완전 보존.
4. AI 캐시·강제 생성·잘못된 출력·실패 Credit 반환·실제 usage 보존·503 1회 재시도·타임아웃·Workspace/사용자 월 한도.
5. 공유 토큰 해시 저장, 폐기·만료, 요청 속도 제한.
6. 고객 수정 요청 시 링크 무효화·재검토 강제, IN_SCOPE 비용/일정 0, 경쟁 변경 요청 차단, 오래된 기준 Scope 공유 차단, 거절 시 버전 생성 없음.
7. 동시에 AI를 요청해도 월 Credit 한도를 초과 예약하지 못함.

AI 테스트는 테스트 전용 로컬 HTTP 공급자에서 엄격 JSON Schema 요청과 응답을 검증합니다. 실제 모델의 의미 분석 품질·실계정 과금·외부 네트워크 호환성을 검증한 것은 아닙니다.

## 검증 중 보완한 사항

- 승인 문서와 승인 대기 내용에 DB 불변성 트리거 적용.
- 오래된 Scope 초안 공유 방지 및 프로젝트 행 잠금으로 중복 승인 방지.
- 추가 기능이 기존 제외 범위와 충돌하지 않도록 담당자의 명시적 해제 선택을 고객에게 표시하고 새 버전에만 반영.
- 승인 후 견적 화면이 최초 견적이 아니라 최신 승인 스냅샷의 누적 금액을 사용하도록 수정.
- Next.js의 재사용되는 레이아웃에서 오래된 상태를 보여주던 중복 배지 제거. 실제 상태는 문서·프로젝트 목록에 표시.
- 변경 검토·고객 의견을 Workspace 수정으로 표시하던 감사 기록 제목 수정.
- 운영 빌드의 병렬 작업자가 동일한 PGlite 폴더를 열지 않도록 빌드 단계 DB 초기화 분리.
- 취약한 중첩 esbuild 의존성 갱신. 스키마 생성·린트·빌드 호환성 재검증.

## 남은 외부 검증

- 실제 AI API 키·지원 모델·공급자 단가를 연결한 뒤 자연어 분석 품질과 실제 usage를 확인해야 합니다.
- 관리형 PostgreSQL 연결, HTTPS 배포, Vercel 실행, 외부 고객 접속은 별도 환경이 없어 미검증입니다.
- 데스크톱 화면은 시각 검증했습니다. 브라우저의 모바일 뷰포트 지정이 실제 화면 폭에 반영되지 않아 모바일 시각 검증은 완료로 기록하지 않습니다. 반응형 CSS는 포함되어 있습니다.
- 이메일 인증·비밀번호 복구·외부 초대 메일은 구현 범위에 포함하지 않았습니다. 공개 서비스 운영 전 필요한 정책을 결정해야 합니다.
